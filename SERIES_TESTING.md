# Series and anime metadata integration
- Home, Movies, Series, Anime, Search tabs. Existing movie catalog IDs, history, and playback paths retained. New TV discovery uses TMDB with the user's session read access token; Cinemeta is the fallback for series metadata and conservative anime classification. Anime discovery uses Japanese origin + Animation genre, not all international animation. Some Japanese productions may be absent and non-Japanese anime-style titles may be classified as series.
- Configure Menu > TMDB / streaming availability. The token stays in memory, not the database, source, APK or preferences; no new production credential is provided. TV metadata requests are authenticated loopback POSTs, external TMDB calls use HTTPS. Search calls movie and TV catalogs separately and deduplicates by ID; cross-provider IMDb/TMDB identity reconciliation is not yet implemented.
- TMDB TV ID and IMDb series ID remain distinct; season 0 (specials) and original provider episode numbers retained. SQLite persists TV catalogs and season/episode JSON; 12 TV catalog records and 24 episode records at 256 KiB maximum per record, 24h freshness, up to 30 days stale fallback. Existing movie cache and history retained. No persistent poster file cache.
- The season/episode screen uses a gradient backdrop, horizontal season tabs and landscape episode rail with focus transitions, description and runtime. No fabricated episode artwork; fall back to show artwork. Selecting an episode offers the existing user-supplied authorized media source flow. No automatic episode source discovery, subtitles, episode resume or autoplay-next added.
- Windows validation: run flutter analyze/test and full Android rebuild; verify movie startup and history, home/series/anime tabs, search, season switching and focus, special episodes and long rails, provider pills on TV titles, invalid/missing token, offline cached episodes, and legitimate media playback. Flutter/Dart/JDK absent on server. TMDB/JustWatch distribution licensing and attribution requirements still need verification.
