# isme.gg v0.2.0 — Playback Engine Update

- Optional experimental Native Direct playback transport, with adaptive buffering and optional Fast Startup.
- Improved startup piece scheduling and recovery while seeking or resuming.
- Storage protection, a higher 7 GiB selected-media ceiling and improved playback failure handling.
- A version-specific What's New dialog lets you choose your playback preferences after updating.
- Legacy HTTP remains the default. Change your choice anytime under Settings > Experimental playback.

Experimental performance depends on device, source availability and connection. If playback is incompatible, return to Legacy HTTP in Settings. No separate streaming server is required.
