# Platform discovery and Home navigation

- Home orders the hero, Explore platforms, Continue watching, trending movies, popular series, popular anime, Filipino and Korean movies, action and horror. Movies retains broader genre shelves. Platform selection changes the catalog only on activation, never merely on remote focus. Continue watching remains independent of the filter.
- Regional provider IDs and logos come from the TMDB movie/TV watch provider directory. Worldwide directory assets are artwork only; they cannot assert regional availability. Provider names are matched using explicit aliases, not guessed numeric IDs. Missing/unavailable artwork falls back to a text label. The landing page /web assets were not located in this checkout.
- Platform discovery uses TMDB watch_region + provider IDs + flatrate/free/ads filters (not rent/buy), excluding future dates. No inference of platform exclusivity. Empty collections are hidden; unsupported regions and missing credentials have explicit empty states.
- The prior orange Connect TMDB banner is removed. First-time setup is still necessary: Menu > TMDB / streaming availability > API read token. The supplied token is encrypted locally with Android Keystore, restored on startup, and clearable. Nothing is hardcoded in source. If encryption fails, token remains session-only with a warning. Unconfigured ordinary catalogs use the existing Cinemeta and bundled fallbacks.
- SQLite keys include region, provider IDs, media kind and row. 24 platform catalog records and 4 directory records, max 256 KiB each, 24-hour freshness and 30-day maximum stale fallback; no media bytes. The Dart heap retains only one selected platform's shelves. Availability and artwork are independent of playback.
