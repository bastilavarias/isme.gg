# Mobile experience (Android) — v0.5 foundation

- Device routing uses the existing Android TV UI-mode signal. TV's CinemaHome, CinemaShelf, SeriesPage, native engine, platform rail and search remain in place. MobileHome and MobileDetails are separate presentation components; the shared player selects touch-only controls on phones. No Gradle, Java or native resolver changes.
- Phone navigation: bottom Home / Search / Browse / My List, landscape NavigationRail, category chips, platform rail, swipe-only featured art, lazy fixed-size poster shelves and collection grids. Platform + movie/series/anime filtering uses existing regional discovery. Pinoy resets the provider filter rather than claiming unsupported combined origin filtering.
- Search uses the native keyboard, debounced results, local catalog matching, recent queries and content-type filters. Local bookmarks are stored separately from existing watch history; completed titles are not a full historical log. New watch records include duration for accurate progress bars; old records show watched minutes instead.
- Details use a cinematic header, primary play/resume action, saved titles, copy title and a scrollable episode list with season sheet. Existing autoplay and subtitle/audio settings remain. Recommendations, full system share sheet, data-saving bandwidth mode, full watched-history ledger and cross-device bookmark sync are not implemented in this pass.
- Mobile player: explicit fullscreen/orientation request, tap visibility, double tap seek, center controls, touch lock, scrub on release, bottom sheets for existing playback settings. Actual orientation and system-bar behavior depend on Android version/device policy. The controller is not recreated just to change orientation.
- Verify on Windows: flutter analyze; flutter test; flutter test test/mobile_experience_test.dart. Run Android TV emulator regression (navbar, D-pad, rails, focus, episode selector, playback, subtitles, autoplay). Test phone emulator 360x800 and 390x844 logical px, landscape, increased font scale, keyboard, platform filtering, saved list, orientation during playback, back, screen lock, captions, and app background/resume. Test real S24 Ultra when available. Verify memory and mobile data usage on device.
- Server has no Flutter/Dart SDK. Source checks are not compilation or emulator tests. Do not label this release verified until both device paths pass.
